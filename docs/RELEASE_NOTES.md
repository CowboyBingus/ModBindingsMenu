- No fixed limit on mod bindings: past the 36 native actions, a mod's registration gets an extended binding instead of failing.
- Extended bindings appear on a new MORE MODS tab on both binding pages while there are any; it is offered outside missions only, and extended bindings keep working in missions.
- On MORE MODS, keys are set with the mouse, keyboard or controller; Escape or B cancels and Delete, Backspace or X clears.
- Extended bindings support Press, Release and Hold, alternative keys and modifiers, on keyboard, mouse and any connected controller.
- Extended bindings read the game's own input only when a mod asks for them, and are saved in `ModBindingsMenu.bindings` with a backup.
- While a key is being chosen, mod bindings read `false`, and Escape cancels the choice without closing the page.
- For mod authors: `version` is 4 (`api` stays 1), with `options.backend`, `options.default`, `set_binding`, `binding`, `binding_info` and `extended`; an extended binding without keys reads `false`, never `nil`.
- Fixed: two v1.1 mods that both ask for slot 2 no longer swap keys when their load order changes; earlier saved settings are repaired on first use.
- Prevent resetting mod bindings from restoring hidden developer mouse and controller inputs. These could make a mission-selection click also activate Ship Station Hotkeys' Galactic Map shortcut.
- Fixed: the MODS tab's first section header (and the "no mod bindings installed" line) was blank in every game language except English, Japanese and Simplified Chinese, because it borrowed a game text ID those languages alone have.
- Every text ID the MODS tab borrows now exists in all of the game's languages; six that did not were removed from its pool.
- Up to 59 different texts can show on the MODS tab at once, down from 65.
- Never changes the game's memory protection: a write to a page that is not writable is skipped and logged.
