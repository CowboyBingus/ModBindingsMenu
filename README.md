# Mod Bindings Menu

Mod Bindings Menu now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Mod Bindings Menu's C source is in
[`src/components/mod_bindings_menu`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/mod_bindings_menu).

The standalone Lua mod (v2.3 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/ModBindingsMenu/tree/legacy) branch. Its releases and tags are unchanged.
